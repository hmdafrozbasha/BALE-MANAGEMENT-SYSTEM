# BALE MANAGEMENT SYSTEM

An enterprise Agro Operations and Bale Management platform built for managing raw materials, fermentation plots, production batches, sales invoicing, expenses, and reporting.

## Features
- **Dashboard**: Real-time agro metrics, live fermentation countdowns, and stock-by-stage tracking.
- **Plots & Fermentation**: Real-time tracking of fermentation sections and plot capacities.
- **Production Batches**: Batch assignment, auto calculations for production costs, and yield monitoring.
- **Sales & Invoices**: Client billing, payment receipts, balance tracking, and PDF export.
- **Expenses & Purchases**: Multi-category operations expense tracking and raw material procurement.
- **Supabase Integration**: Role-based access control (Owner, Finance, Staff) and atomic transactional RPCs.
